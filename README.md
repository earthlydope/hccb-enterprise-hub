# HCCB Enterprise Hub

Clickable mobile prototype of the HCCB employee hub. Open it on the web — the app sits inside a phone frame. On a real phone it goes full screen.

## Local

```bash
npm install
npm run dev
```

## Demo

Continue with the work account on the sign-in screen. Approvals, tickets, leave, travel, jobs, search, Copilot, knowledge, and admin actions persist in this browser.

Mock data only — not connected to SAP, ServiceNow, or Microsoft 365.
